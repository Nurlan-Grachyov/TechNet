# TechNet

### Описание проекта
Проект направлен на реализацию модели сети по продаже электроники, состоящей из трех иерархических уровней: заводы, розничные сети и индивидуальные предприниматели. Главная особенность сети заключается в том, что каждое звено связано только с одним поставщиком, причем уровень иерархии определяется отношением между звеньями сети, а не их названиями.

### Технические требования
1. Общая структура сети:<br>
Заводы находятся на самом низшем уровне иерархии (уровень 0).<br>
Розничные сети могут находиться на любом уровне выше нуля (уровень 1+).<br>
Индивидуальные предприниматели аналогичны розничным сетям и располагаются на уровнях выше нуля.<br>


2. Атрибуты каждого звена сети:<br>
__Название__ (обязательно): Уникальное имя предприятия.<br>
__Контакты__ (обязательно):<br>
   * Email (электронная почта).<br>
   * Страна.<br>
   * Город.<br>
   * Улица.<br>
   * Номер дома.<br>
   
__Продукты__ (опционально):<br>
   * Название продукта.<br>
   * Модель продукта.<br>
   * Дата выхода продукта на рынок.<br>
   
__Поставщик__ (может быть пустым): предыдущий по иерархии объект сети.<br>
__Задолженность перед поставщиком__ (число с плавающей запятой): сумма долга в рублях с точностью до копеек.<br>
__Время создания__ (datetime): дата и время создания объекта сети.<br>


3. Интерфейс в административной панели Django: <br>
Вывод списка всех объектов сети. <br>
Возможность быстрого перехода на карточку поставщика путем нажатия на ссылку. <br>
Фильтрация по названию города. <br>
Массовая очистка долгов перед поставщиками. <br>


4. API через Django Rest Framework: <br>
Реализованы CRUD-методы для объектов сети. <br>
Поле «Задолженность перед поставщиком» должно быть доступно только для чтения через API (невозможно изменить через API). <br>
Возможность фильтрации объектов по стране. <br>
Доступ к API предоставляется только активированным сотрудникам (активные аккаунты сотрудников). <br>

__Архитектура проекта__ <br>
- Модели <br>
- Завод: Производственное предприятие, выпускающее электронику.<br>
- Розничная сеть: Продающая организация среднего уровня.<br>
- ИП: Частный предприниматель, занимающийся реализацией продукции.<br>
Каждая модель наследуется от единой абстрактной модели сети и обладает общими характеристиками.

### Логика:
Система строится таким образом, чтобы избежать циклических ссылок между поставщиками и потребителями.<br>
Вся инфраструктура поддерживается централизованно, что облегчает ведение учета продукции и денежных потоков.<br>
Административная панель:<br>
Административная панель предоставляет полный контроль над управлением сетью, позволяя видеть и редактировать списки объектов, смотреть историю транзакций и оперативно решать вопросы с долгами.<br>

### Особенности реализации:
+ Используется комплексный подход к разработке, сочетающий Django ORM и Django Rest Framework.
* Реализована четкая структура данных и маршрутов, что улучшает читаемость и масштабируемость кода.
- Благодаря встроенному инструментарию Django, обеспечивается безопасность и быстрота разработки.
